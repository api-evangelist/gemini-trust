# Gemini Developer Platform API Documentation

> Complete API reference, developer guides, machine-readable specifications (OpenAPI, AsyncAPI), and SDKs for Gemini Spot, Margin, Perpetuals, and Prediction Markets.

## When to Use Gemini Developer Platform

Use this site when you need to build against the Gemini Exchange API, discover a documented endpoint, inspect a machine-readable contract, or choose the right protocol for a trading workflow. Start with the [Gemini Developer Platform overview](https://developer.gemini.com/developers), then choose the [Gemini API Reference](https://developer.gemini.com/api-reference) for REST, WebSocket, or FIX operations.

For automation and agent workflows, read the [Gemini agent instructions](https://developer.gemini.com/agents.md) and [Build an agent](https://developer.gemini.com/build/agent). Use the [Gemini MCP server and agent skills](https://developer.gemini.com/tools) when an MCP client or coding assistant needs Gemini market data or authenticated API capabilities.
